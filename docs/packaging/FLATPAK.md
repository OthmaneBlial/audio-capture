# Previous sandbox package

The old single-file sandbox package is retired. It targeted a removed desktop
runtime and is not a supported installation path for the native Rust app. Do
not use its commands, permissions, checksums, or screenshots as evidence for a
current release.

Install the current native archive from the GitHub release page instead. The
archive names, target matrix, checksum contract, and clean extraction checks
are documented in [the native packaging guide](../../packaging/native/README.md)
and [the release checklist](RELEASE-CHECKLIST.md).

The filename and application identifier are retained in the repository only so
that historical links and metadata can be identified during the migration. No
new sandbox manifest or sandbox release should be added without a separate
product decision and fresh runtime evidence.
