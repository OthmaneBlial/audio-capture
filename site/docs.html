Documentation

A direct path to a working transcription session.

Voice Transcriber is a Linux GTK desktop application. It needs a microphone, a Groq API key, and a Debian/Ubuntu desktop with GTK 3.

Install

git clone https://github.com/OthmaneBlial/audio-capture.git
cd audio-capture
./setup.sh
cp .env.example .env

Open .env and set a new GROQ_API_KEY. Then activate the environment and check the configuration:

source venv/bin/activate
python main.py --check-config
python main.py --list-devices
python main.py

Configure

Settings are resolved in a predictable order:

defaults < ~/.config/voice-transcriber/config.json < environment variables

GROQ_API_KEY overrides any saved key. The application never logs it. Settings are atomically written with owner-only permissions where supported.

Use Settings to choose a microphone, select a spoken language, translate into English, adjust text size and opacity, or keep the window on top. Use python main.py --device INDEX to override the saved microphone for one launch.

Use

  1. Open Settings and choose a microphone if the default is not the right source.
  2. Select Start listening or press Ctrl + Enter. The live input meter should respond when you speak; it is calculated locally and does not save a recording.
  3. Speak normally. The session status shows listening, detected speech, and transcription progress.
  4. Use Copy (Ctrl + Shift + C) or Export to save a text file.
  5. Select Stop listening to finish; a valid in-progress segment is flushed once.

Privacy and data flow

Voice activity detection runs locally. Raw audio is held in memory and is not stored by the app. When speech ends, the app encodes that completed segment in memory and sends it to Groq for transcription. The transcript remains in the app until you clear, copy, or export it.

This is not an offline transcription engine. Do not use it with a Groq key you do not control.

Architecture

The desktop process separates GTK, microphone capture, local VAD, and the Groq boundary. Capture uses a bounded frame queue and a rate-limited local input meter. A two-worker transcription pool accepts only a small number of pending segments, preserving predictable memory and feedback when the network is slow.

Read the full architecture note on GitHub.

Troubleshoot

No API key

Set GROQ_API_KEY in .env, or add it in Settings. Run python main.py --check-config to validate without opening GTK.

Microphone cannot open or is the wrong source

Run python main.py --list-devices, then choose an index in Settings or start with --device INDEX. Confirm the desktop session can use the microphone in PipeWire or PulseAudio settings, then start a new session.

Groq cannot be reached or rate limits requests

Check the network and key status, then wait a few seconds. The request queue is deliberately bounded instead of accumulating unbounded work.
